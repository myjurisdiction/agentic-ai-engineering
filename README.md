# Agentic AI — Concepts, Experiments & Implementations

This repository documents my journey into **Agentic AI**, following Andrew Ng's _Agentic AI_ course on [DeepLearning.AI](https://www.deeplearning.ai/).

The goal is to move beyond traditional LLM-based applications and understand how to design, build, and evaluate **autonomous and semi-autonomous AI systems** capable of reasoning through complex tasks, using tools, making decisions, and executing multi-step workflows.

As a software engineer, my focus is not just on understanding the theoretical concepts, but on translating them into practical, production-oriented implementations.

### What You'll Find Here

- **Core Concepts:** Notes and explanations covering agentic workflows, reflection, tool use, planning, and multi-agent collaboration.
- **Hands-on Implementations:** Code examples and experiments demonstrating agentic design patterns.
- **Evaluations & Optimization:** Techniques for measuring agent performance, identifying failure points, and iteratively improving workflows.
- **Real-World Applications:** Practical projects exploring how AI agents can automate workflows and solve engineering problems.

### Learning Philosophy

**Understand the concepts. Build the systems. Evaluate the results. Iterate.**

Rather than treating AI agents as black boxes, this repository focuses on understanding their underlying design principles, implementation trade-offs, and engineering challenges.

The repository will evolve as I progress through the course, experiment with different approaches, and build increasingly sophisticated agentic applications.
